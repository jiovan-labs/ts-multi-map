🏅 適用於 TypeScript 的多鍵/值對應與區間對應 👍

## 特性

✅ 支援多鍵/多值，且支援只讀模式

✅ 支援區間，且支援只讀模式

## 快速開始

您可以在 TypeScript 專案中依下列方式安裝本套件：

```bash
$ npm install @jiovan-labs/ts-multi-map --save
```

隨後，您可以依下列方式引入元件：

```jsx | pure
import { MultiKeyMap, ReadonlyMultiKeyMap } from '@jiovan-labs/ts-multi-map';
import { MultiValueMap, ReadonlyMultiValueMap } from '@jiovan-labs/ts-multi-map';
import { RangeMap, ReadonlyRangeMap } from '@jiovan-labs/ts-multi-map';
```

祝您使用 `ts-multi-map` 編碼愉快 ✌️
