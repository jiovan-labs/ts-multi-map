🏅 Multiple key/value map & range map for typescript 👍

## Features

✅ Supports multiple keys/values, with readonly capability

✅ Supports ranges, with readonly capability

## Quickstart

You can install this package in your typescript project as follows:

```bash
$ npm install @jiovan-labs/ts-multi-map --save
```

Then, you may import components as follows:

```jsx | pure
import { MultiKeyMap, ReadonlyMultiKeyMap } from '@jiovan-labs/ts-multi-map';
import { MultiValueMap, ReadonlyMultiValueMap } from '@jiovan-labs/ts-multi-map';
import { RangeMap, ReadonlyRangeMap } from '@jiovan-labs/ts-multi-map';
```

Enjoy your coding journey with `ts-multi-map` ✌️
